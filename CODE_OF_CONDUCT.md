# 📜 Code of Conduct — Taeafi (تعافي)

## Our Pledge 🤝

We, as members, contributors, and maintainers of the **Taeafi** project, pledge to make participation in our community a **harassment-free experience for everyone**, regardless of:

| Category | Examples |
|----------|----------|
| **Age** | All ages welcome |
| **Body Size** | No body shaming |
| **Disability** | Visible or invisible |
| **Ethnicity** | All backgrounds |
| **Gender Identity** | All genders |
| **Level of Experience** | Beginner to expert |
| **Nationality** | All countries |
| **Personal Appearance** | No appearance-based judgment |
| **Race** | All races |
| **Religion** | All faiths and beliefs |
| **Sexual Identity** | All orientations |

---

## Our Standards 📏

### ✅ Expected Behavior

Examples of behavior that contributes to creating a **positive environment**:

| Behavior | Description |
|----------|-------------|
| 🤝 **Welcoming** | Using friendly and inclusive language |
| 🎯 **Respectful** | Respecting differing viewpoints and experiences |
| 💬 **Constructive** | Accepting constructive criticism gracefully |
| 🌍 **Community-Focused** | Focusing on what is best for the community |
| 💙 **Empathetic** | Showing empathy towards other community members |
| 🤗 **Supportive** | Helping others learn and grow |
| 📚 **Educational** | Sharing knowledge patiently |
| 🙏 **Grateful** | Acknowledging contributions and efforts |

### ❌ Unacceptable Behavior

Examples of **unacceptable behavior** include:

| Behavior | Description |
|----------|-------------|
| 🚫 **Harassment** | Any form of harassment, public or private |
| 🚫 **Offensive Comments** | Related to gender, religion, race, or personal attributes |
| 🚫 **Sexual Content** | Sexualized language, imagery, or unwelcome advances |
| 🚫 **Trolling** | Deliberately inflammatory or off-topic comments |
| 🚫 **Personal Attacks** | Insulting, derogatory, or demeaning remarks |
| 🚫 **Doxing** | Publishing others' private information without consent |
| 🚫 **Intimidation** | Threatening or aggressive behavior |
| 🚫 **Stalking** | Unwanted following or monitoring |
| 🚫 **Spam** | Unsolicited promotions or irrelevant content |
| 🚫 **Impersonation** | Pretending to be someone else |

## Our Responsibilities 🛡

### Maintainer Responsibilities

Project maintainers are responsible for:

| Responsibility | Action |
|---------------|--------|
| **Clarification** | Explaining and enforcing standards of acceptable behavior |
| **Moderation** | Taking appropriate and fair corrective action |
| **Removal** | Removing comments, commits, code, or contributions not aligned with this Code of Conduct |
| **Banning** | Temporary or permanent banning of contributors for repeated violations |
| **Transparency** | Communicating moderation decisions clearly when appropriate |

### Scope of Enforcement

This Code of Conduct applies to:

| Space | Examples |
|-------|----------|
| 🏠 **Project Spaces** | GitHub repository, issues, pull requests, discussions |
| 🌐 **Public Spaces** | When representing the project at events or online |
| 📧 **Private Communication** | Project-related emails, messages, or chats |
| 📱 **Social Media** | Official project accounts or when representing the project |

## Enforcement ⚖️

### Reporting Process

If you experience or witness unacceptable behavior:

| Step | Action |
|------|--------|
| 1️⃣ | **Document** the incident (screenshots, links, dates) |
| 2️⃣ | **Report** to the project team via available channels |
| 3️⃣ | **Wait** for acknowledgment (within 48 hours) |
| 4️⃣ | **Cooperate** with any investigation |
| 5️⃣ | **Receive** notification of the outcome |

## Cultural Considerations 🌍

### Arabic & Islamic Context

As this project primarily serves an **Arabic-speaking, Muslim audience**:

| Consideration | Guideline |
|---------------|-----------|
| 🕌 **Religious Respect** | Respect all Islamic sects and schools of thought |
| 📿 **Spiritual Content** | Discussions on religious content should be respectful and scholarly |
| 🗣️ **Language** | Arabic or English are both acceptable |
| 🤲 **Sensitivity** | Be mindful of cultural and religious sensitivities |
| ☪️ **Inclusivity** | Sunnis, Shias, and all Muslims are equally welcome |

### Interfaith Respect

While this app includes Islamic spiritual content:

| Principle | Application |
|-----------|-------------|
| ✨ **Open to All** | Users of any faith (or no faith) are welcome |
| 🤝 **Respect** | No proselytizing or religious pressure |
| 🧠 **Focus** | The app's primary focus is health and recovery |
| 📚 **Educational** | Religious content is for spiritual support, not debate |

## FAQ ❓

### Q: What if I disagree with a moderation decision?

**A:** You may appeal by contacting the project maintainer. Appeals will be reviewed within 7 days.

### Q: Can I report anonymously?

**A:** Yes, but providing contact information helps us follow up if needed.

### Q: What if the violation happened outside project spaces?

**A:** If it affects the project community, it may still fall under this Code of Conduct.

### Q: Are maintainers held to the same standards?

**A:** Yes — maintainers are held to an even higher standard of behavior.
